# Scan CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the documented `habitat scan` command over the existing local world-scan API.

**Architecture:** A new focused CLI module parses Commander options, calls `scanWorld` from `src/api/world.ts`, and formats the returned scan. It does not use raw HTTP, registration state, or Kepler transport.

**Tech Stack:** TypeScript, Bun test, Commander.

## Global Constraints

- Command shape: `habitat scan --x 3 --y -2 --strength 60`.
- `--x`, `--y`, and `--strength` are required integer options; strength is 0–100.
- `--radius` is an integer 0–5 and defaults to 0.
- `--json` prints the complete API JSON response without formatting.
- Radius 0 prints all resource probabilities and the nullable quantity estimate for one tile.
- Larger radii print coordinates, distance, terrain, top candidate, confidence, and estimated quantity per tile.
- Verify against a running isolated Habitat service.

- [ ] **Step 3: Implement minimal command and formatters**

```ts
program.command("scan")
  .requiredOption("--x <integer>", "Current x coordinate")
  .requiredOption("--y <integer>", "Current y coordinate")
  .requiredOption("--strength <0-100>", "Effective sensor strength")
  .option("--radius <0-5>", "Scan radius", "0")
  .option("--json", "Print the complete JSON response")
  .action(async (options) => {
    const scan = await dependencies.scanWorld({
      x: parseIntegerOption(options.x, "x"),
      y: parseIntegerOption(options.y, "y"),
      sensorStrength: parseBoundedIntegerOption(options.strength, "strength", 0, 100),
      radiusTiles: parseBoundedIntegerOption(options.radius, "radius", 0, 5),
    });
    console.log(options.json
      ? JSON.stringify(scan, null, 2)
      : scan.scan.radiusTiles === 0
        ? formatSingleTileScan(scan.scan.tiles[0])
        : formatScanSummary(scan.scan.tiles));
  });
```

Register `registerWorldCommands(program)` from `src/cli.ts`. The formatter must label a null estimate as `none`.
